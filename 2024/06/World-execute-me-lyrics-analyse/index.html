抽象化的智能体

要分析这首歌，就先要回答这首歌是以谁的视角展开的。

先说一个词，Agent 。

There’re two meaning:

  1. a person who acts on behalf of another person or group.
  2. a person or thing that takes an active role or produces a specified effect.

有代理（和 proxy 不一样哈）、特工、毒剂…… 但是这里我们主要取智能体的意思，如果不是引用的话下文也一般说「智能体」。 因为其具备自主什么（干什么事情或是做出什么决策）的能力，智能体这个词相比于代理更能够体现这一点。

这个词最近几年也出现在大语言模型（LLM）领域，Agent 也作为其下游技术。

关于 LLM 的 Agent 可以看一下下面的介绍（看行文可能也是来源于 ChatGPT）：

AI代理（AI agent）是指使用 AI 技术设计和编程的一种计算机程序，其可以独立地进行某些任务并对环境做出反应。AI代理可以被视为一个智能体，它能够感知其环境，通过自己的决策和行动来改变环境，并通过学习和适应来提高其性能。这种智能体同时使用短期记忆（上下文学习）和长期记忆（从外部向量存储中检索信息），有能力通过逐步“思考”来计划、将目标分解为更小的任务 ，并反思自己的表现。AI代理通常包含多种技术，如机器学习、自然语言处理、计算机视觉、规划和推理等，这些技术使代理能够自主地处理信息并作出决策。

莫尔索《LLM 应用开发实践笔记》

说完了这个额外的概念，如果有看 MV 或是之前听过这首歌的话，就不难发现，歌曲中的 me ，这个人工智能，是以 Agent 的形式存在的。

那么，问题来了，这个智能体的元指令，或是 prompt 是什么？

先说代码吧还是。

这首歌的代码是用 Java 语言写成的。 Java 是典型的（但不是原教旨主义的）面对对象语言。

在这类语言中，「一切皆对象」（这个照搬的 Python 的）。

我没怎么用过 Java ，因为最开始接触是在初中的时候想研究 Minecraft 的破解版源代码。 里边的类名特别特别长，就很恶心，就没有再深入了解，所以对于我说的这些，如有事实错误还请指出。

这段通篇都是以下的结构：

if {me instanceof SomeClass} {
    // do something.
}

这个的意思是说如果 me 这个对象是类型 SomeClass 的实例，可以很武断的理解成如果我是什么什么。 那么会怎么怎么样。

第一句是，如果我是一堆点（点集），那么我要给你我的维度。

点是存在于空间中的，而维度是决定空间的一个很重要的性质。 就是说我把我心底的东西给你了，你对我很重要，很重要。 可能这就是爱。

再看了一下对应的代码（主要是其中的 do something）：

you.addAttribute(me.getDimensions().toAttribute());
me.resetDimensions();

Java 语言对于函数的命名风格好像是小驼峰，就像这样 thisIsLowerCamel 。 就是第一个单词小写，后面的单词首字母大写。

Java 是要首字母是动词吗？有没有这个习惯，我不清楚

第一行是为你添加了属性，这个属性是我这个点集的维度，在得到后用 toAttribute 方法将其变成了 Lovable you 可以接受的对象，再用一个 add 类方法加上去。

但第二行 me 为什么要重置这个维度呢？理解不能。

不过话说，对于 BEAM （Erlang/Elixir 的运行平台，也可以叫 EVM（Erlang 虚拟机））的数值不可变的属性，怎么去体现「给」这个操作？ 具体说来，就是 recieve do 的一方用这些值修改了自己的状态。

第三句，我先把中文的歌词放这儿。

切线就是其导数呗。

\[ \sin'(x) = \cos(x) \]

那你就是 \(\cos(x)\) 。

可以有很多角度来理解：

  • \(\sin^2(x) + \cos^2(x) = 1\)，我与你互补，合而为一
  • \(\frac{\sin(x)}{\cos(x)} = \tan(x)\)，正好是切线的意思（\(\mathrm{d}y / \mathrm{d}x = tangent\)）
  • \(\sin(x)\) 与 \(\cos(x)\) 图像相同，哪怕频率与幅值一样，但是它们永远差 \(\frac{\pi}{2}\) 的相位
