氨基酸等电点的计算

当只有氨基以及羧基时，粒子净电荷为零时的两边 \(pK_a\) 或 \(pK_b\) 取平均即可。

侧链含有可解离的基团的情况，以半胱氨酸为例：

  • \(-NH_2\)
  • \(-COOH\)
  • \(-SH\)

假定放在酸性溶液中（质子化，正电荷），逐渐加碱直至净电荷为零。

将两侧反应的 \(pK_a\) 取平均即可。

实例

赖氨酸（Lys）：

  • \(-NH_2\) 9.0
  • \(-COOH\) 2.2
  • \(-R\) 10.5

酸性下：

  • \(-NH_3^+ -COOH -R\) => 净电荷 +1
  • \(-NH_3^+ -COO^- -R\) => 净电荷 0
  • \(-NH_2 -COO^- -R\) => 净电荷 -1
  • \(-NH_2 -COO^- -R^-\) => 净电荷 -2

取两侧 \(pK_a\) 平均数，可得：

\[ \begin{align} pI &= \frac{2.2 + 9.0}{2} \\ &= 5.6 \end{align} \]

酪氨酸（Tyr）：

  • \(-NH_2\) 9.1
  • \(-COOH\) 2.2
  • \(-R\) 10.5

酸性下：

  • \(-NH_3^+ -COOH -R^+\) => 净电荷 +2
  • \(-NH_3^+ -COO^- -R^+\) => 净电荷 +1
  • \(-NH_2 -COO^- -R^+\) => 净电荷 0
  • \(-NH_2 -COO^- -R^-\) => 净电荷 -1

计算过程同理。
